v1.0

More intentional, not more minimal.

Typography carries the hierarchy, neutrals carry the interface, and color appears only when it has a role. Every component here is plain CSS driven by semantic tokens, so it works in any framework.

  • Typography does the heavy liftingConfident headings, readable body, few deliberate weights.
  • Buttons are designedIntentional sizes, surfaces, alignment and feedback.
  • Quiet surfacesNeutrals carry the interface; color has a job.
  • Clarity over decorationNo gradients, glows or ornamental helper copy.
  • Polish without lossSimplify presentation, never capability.

Color

Warm neutrals in light mode, layered graphite in dark mode. Status colors signal state only. Each project sets its own accent through --brand.

Spacing & shape

A 4px base grid with an 8px rhythm. Radii grow with the size of the surface; pills are reserved for prominent actions.
